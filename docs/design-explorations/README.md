# Crays UI/UX explorations

These are high-fidelity concept boards for the active-room journey. They are
direction-setting mockups, not implemented screens or production credentials.

The approved direction is documented in the [Night Playlist design package](night-playlist/README.md), which maps the actual Expo Router screens to
mockups and motion contracts.

Each board covers the same six-step loop:

1. Nearby room discovery
2. People visible in the selected room
3. The room-scoped feed
4. A person profile card
5. Selecting and reviewing a drink gift
6. My Night with order progress

| Concept | Mockup | Core idea |
| --- | --- | --- |
| Room Radar | [room-radar-v1.png](room-radar-v1.png) | Explore the room spatially, then act on a person. |
| Live Bulletin | [live-bulletin-v1.png](live-bulletin-v1.png) | Treat the venue as a live editorial bulletin. |
| Night Playlist | [night-playlist-v1.png](night-playlist-v1.png) | Organize the night around current and upcoming moments. |

The examples use synthetic names, venue content, portraits, drinks, and prices.
They must be replaced with relay-backed data before implementation.
